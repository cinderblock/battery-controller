ANSWER TO YOUR QUESTION
================================================================================

Info packet bytes 14-15 (0x11, 0x86) are DEVICE FIRMWARE IDENTIFIERS.

They are NOT looked up in the software string table because:
1. They are sent BY THE DEVICE, not generated by the software
2. The software ignores these bytes for identification
3. No lookup table maps these codes to device models exists in eb.exe
4. The software uses the user's combo box selection instead

================================================================================

To build a device identification system, you need to:
1. Test each device model one by one
2. Read info packet bytes 14-15 from each
3. Build a manual lookup table:
   0x11, 0x86 -> EBC-A40L (confirmed)
